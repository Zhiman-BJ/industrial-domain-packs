# CUDA Pack provenance

The original MCP transport, Compiler/Evaluator adapters, Harness Runtime plugin,
aggregate Verifier and adapted Skill are maintained in industrial-domain-packs.
They reuse a private, separately provisioned CUDA-Agent-Harbor implementation.
No private upstream code, task corpus, images or model credentials are included
in this public package.

`locks/upstream.json` pins reviewed CUDA-Agent-Harbor commit
`6e94914b5c857e69755c2362f1745d6599426009` and file hashes. The hashes cover the
native workers, candidate transport, policy/audit helpers, capability contract
and allocation recipe. The service checks installed worker bytes before calls.
Reference model, GPU, immutable image and local/remote Verifier identities bind
each deployment and receipt. The source commit and actual installed bytes are
checked separately; an old host checkout does not establish an image identity.

Native tools and the private upstream retain their own terms. They are external
execution dependencies. This package's MIT license covers only its original
adapter code and documentation. Source/contract tests do not establish GPU or
Harness application qualification.

`locks/rtx4090-image.json` separately pins the immutable installed image, its build labels and prepared dispatch/protected-file hashes. These derived wrappers are not identical to the raw paper-runtime files in the upstream source snapshot. The service verifies the reviewed installed image rather than asserting those generated bytes are a verbatim source import. See `QUALIFICATION.md` for native and application scope.
