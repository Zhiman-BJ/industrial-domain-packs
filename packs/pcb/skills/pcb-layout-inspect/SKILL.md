---
name: pcb-layout-inspect
description: Review PCB board geometry and routing context.
---

Open the selected .kicad_pcb or .kicad_sch project artifact in the registered KiCad Viewer to inspect geometry, layers, nets, footprints, and schematic symbols. The Viewer uses a local KiCanvas runtime and is read-only; it does not connect to a running KiCad editor. State the source artifact and revision for each observation. Do not infer DRC, ERC, manufacturing readiness, or electrical correctness from a preview alone. Changes and verification require Domain Runtime tools when available.
